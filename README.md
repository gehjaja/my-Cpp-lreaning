# 我的 C++ 学习记录

VS2026 上课与练习的 C++ 代码，按课上进度分目录存放。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `第一次上机/` | 第一次上机课：1-1、1-2、1-3 |
| `第二次上机/` | 第二次上机课：2-1 ~ 2-4 |
| `练习/` | 课后练习：9.18、9.18.02、9.19、0921、26.10.14 |

每个子目录都是一个独立的 Visual Studio 项目（`.slnx` + `.vcxproj` + `.cpp`）。

## 编译运行

用 Visual Studio 2026 打开对应的 `.slnx` 即可，或直接打开 `.vcxproj`。

## 说明

仓库只保存源码和工程文件；`.vs/`、`x64/` 等编译缓存与可执行文件已由 `.gitignore` 排除，克隆后自行编译生成。
